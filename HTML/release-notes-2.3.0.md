# StarTasks 2.3.0 · 手感与平板适配

## 更跟手了

- **背景动效不再抢性能**：原来背景粒子每帧都在读样式、每帧重建渐变，滚动和点击会被拖慢。现在只在需要时更新，页面切到后台自动暂停。
- **弹窗打开时背景不再跟着滚**：以前手指在遮罩上滑动会把下面的页面带跑，关掉窗口位置就偏了；现在弹窗期间背景锁住。
- **横向列表不抢手势**：日历工具栏、课程图例、看板列这类横向滚动区，斜着划不会先竖后横地抖一下。
- **列表滚动更稳**：纵向/横向滚动区都声明了手势方向，滚到边缘也不会整页回弹。

## 动画补上了

- 切页、弹窗、面板三种入场动画以前在样式里**根本没有定义**（等于硬切），现在补齐：淡入 160ms、面板 220ms、切页 240ms，统一缓动。
- 触摸设备上去掉了毛玻璃模糊（安卓上每帧重算，掉帧明显），改为近实色面板，文字更清楚。

## 平板（iPad / 安卓平板）

- 平板以前落在「手机优化没启用、桌面版又装不下」的空档：课表 8 列每列约 100px、成绩 6 列表格被裁切、日历强制横向滚动。
- 现在 **窄屏或触摸设备统一按紧凑形态**：课表按天清单、成绩卡片、日历月视图 + 当日清单。
- 平板也用**底部导航**（总览/日历/课程/学业/班级），侧栏改为抽屉；按钮不再「只有鼠标悬停才出现」。

## 桌面端

- 切页有淡入位移过渡，不再硬切。
- 成绩表格在极窄窗口下可横向滚动，不再被裁切。
