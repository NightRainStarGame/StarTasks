# StarTasks 2.1.0

## 班级

- **成员权限可编辑**：创建者可为任一成员设置「管理员」，弹窗里直接写明该角色能做什么——发布公告、发布作业、管理成员、关闭接龙与投票；普通成员仍可发起接龙和投票。
- **接龙更好用**：支持「一键接龙（我参加）」，标题旁显示你是否已参加，可一键复制完整名单。
- **投票更清楚**：多选、实时票数与百分比进度条、截止时间、随时改票，结束后自动锁定。
- **聊天显示身份**：每条消息都带头像和昵称，自己的消息标「(我)」，头像加载失败自动退回彩色首字圆标。

## 云端与账号

- **云备份恢复可用**：上传/恢复不再被安全校验拦下，登录后自动完成校验，点击即可备份。
- **左下角显示网站账号**：登录后显示你的用户名与头像，未登录时回退本地档案。

## 更新方式

- 应用内「设置 → 内容更新」可直接更新前端内容，**不用重新安装**；更新完成后提示卡自动收起。
- 面板会显示「当前运行」是内置版本还是更新后的内容，以及已应用的内容版本号。

## 界面修复

- 课程详情面板不再半透明（此前能透出底层课表）。
- 错误提示页恢复背景色，班级页的角色名、多选标记、编辑按钮恢复配色。
- 窗口关闭按钮、最小化/最大化、拖动标题栏均已修复。

## 已知限制

- 班级服务需在服务端部署后使用；未部署时相关页面会提示服务不可用。
- 内容更新只更新界面与逻辑，涉及原生能力的改动仍需安装新版本。
