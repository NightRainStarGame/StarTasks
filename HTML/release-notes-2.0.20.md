## 2.0.20 更新内容

- **班级成员页不再崩溃**：修复 `Invalid time value`（服务端字段是 `joined_at`、前端读 `joinedAt` 导致的 undefined 日期）。日期格式化改为永不抛错的 `fmtDate`，缺失显示 `—`。
- **班级字段统一**：接口响应统一做 snake_case → camelCase 归一化，成员/公告/接龙/投票/聊天的字段不再缺失。
- **聊天显示账号头像 + 昵称**：发送消息时带上昵称与网站头像；渲染时三级兜底（消息自带 → 成员表 → 当前账号头像 → 彩色首字圆标），头像加了描边。
- **内容热更新入口**（设置 → 软件更新 → 内容更新）：显示「当前壳版本 / 线上内容版本」，一键更新后窗口自动重载；没有安装包直链也能用，不再依赖旧的「下载 exe」流程。
- **更新提示不再误报**：版本比较改为数值比较，线上内容比当前旧时不会提示「发现新版本」。
- **UI 修复**：班级页 `neon-cyan` 未定义（角色名/多选标记/编辑按钮不上色）、`bg-ink-card`（错误页无背景）、`text-text`（关于页正文色）等无效类名全部修正。
- **热更状态持久化**：已应用的内容版本存进 SQLite（切到 `sthot://` 后 localStorage 会换命名空间，存那里会丢、导致重复提示）。
- **班级服务错误可见**：服务端 404/401 会显示具体地址与状态，不再笼统提示「班级服务升级中」。

### 已知限制

- 班级服务端（`server/class-module`）尚未部署到 120.53.9.81:8100，创建/加入/聊天等功能在此之前都会返回 404。
- 内容热更新首次生效后 WebView 源会切到 `sthot://`，**需要重新登录一次网站账号**（SQLite 数据不受影响）。
- 仅改前端时用热更新即可；改到 Rust/权限/原生能力仍需重新安装。
